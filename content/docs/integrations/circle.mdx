## Overview

Circle is where many course creators and paid communities live. AnswerLoops ingests posts and comments from the spaces you choose, runs them through the standard triage → retrieval → confidence-review → escalation pipeline, and returns grounded answers.

Answer delivery has two modes, set per connection:

1. **Review-first.** The drafted answer lands in your AnswerLoops inbox for a team member to review and paste back. Nothing posts to Circle automatically.
2. **Automatic replies.** High-confidence answers post back into the thread directly, the same as Discord or Slack.

## How it connects

| You provide | Where it comes from |
| --- | --- |
| Circle API token | **Settings → API** in your Circle admin |
| Watched spaces | Chosen in AnswerLoops settings after connecting |

## Plan availability

Circle is a Standard-plan-and-above channel, gated the same way as Slack and GitHub.
